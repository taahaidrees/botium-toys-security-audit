# Internal Security Audit — Botium Toys

**Simulated cybersecurity portfolio project** | Google Cybersecurity Professional Certificate

This project assesses a fictional toy retailer’s security controls and course-defined compliance best practices using a supplied scope and risk assessment report. The scenario assigns an **8/10 risk score**.

## Key results

- **Security controls:** 7 YES / 7 NO (14 assessed)
- **Course compliance checklist:** 4 YES / 8 NO (12 assessed)
- **Primary gaps:** least privilege, separation of duties, encryption, backups, disaster recovery, intrusion detection, and centralized password management
- **Existing but weak controls:** password policies and legacy-system monitoring/maintenance

## Method and limitations

Completed all 26 assessment items, including 14 security controls and 12 PCI DSS, GDPR, and SOC checklist items. Documented findings and remediation recommendations based on the supplied fictional case study. No real systems were tested; these checklist judgments are not formal PCI DSS, GDPR, or SOC compliance determinations.

## Skills demonstrated

Security auditing, risk assessment interpretation, control evaluation, least privilege, data protection, business continuity, PCI DSS/GDPR/SOC awareness, evidence-based reporting, and remediation prioritization.
